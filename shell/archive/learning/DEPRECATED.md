# `shell/archive/learning` - deprecated lesson units

The first curriculum (first five notes, the octave, B flat and F sharp, the octave key, C major,
G major), retired when the lessons were replaced by the four note groups in
`shell/src/commonMain/.../learning/catalog/units/NoteGroupUnits.kt`.

- **Not built.** These files sit outside every source set, so nothing here is compiled or tested.
- **Not reachable.** No unit here is in `SaxTrainerCurriculum`.
- **Not maintained.** Changes elsewhere are not carried over, so they may stop compiling if copied
  back as they are.

Kept for reference and possible reuse only.
